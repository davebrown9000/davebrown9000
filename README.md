## Selected project

### [Evidence-Governed AI Document Engineering](https://github.com/davebrown9000/evidence-governed-ai-document-engineering)

A domain-agnostic case study in evidence-grounded AI document workflows. The public repository includes a small, independently authored Python demonstration of deterministic claim-to-evidence validation, fictional examples, unit tests and GitHub Actions CI. It describes the broader AI-assisted architecture without distributing the original implementation.

## Engineering approach

- **Evidence and provenance:** Keep source facts, interpretations and generated content distinct and traceable.
- **AI with guardrails:** Combine AI-assisted analysis and drafting with explicit requirements, deterministic checks and human oversight.
- **Data integrity:** Validate schemas, relationships, status and approval before downstream use.
- **Reproducibility:** Use version control, automated tests and clear boundaries for what an example actually proves.
